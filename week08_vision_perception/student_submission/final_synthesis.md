The 3 missions taught me how using visual evidence, we can determine how to identify objects through the use of colors/hues/saturation/brightness and how pixel's themselves cannot be used to identify what an object is and need some sort of category to be placed into. This was seen in the classical/learned detector comparison where the classical could select the object however did not give it a name because it just saw a general most grouped up pixels in the masking and created a box around it, with the learned detector however when there were no obstacles and was just a normal image it managed to identify which part of the mug was the cup and detect and identify it while cutting out the handle. The pillar centering mission explains how just detecting color can't be used to identify the object and distance of the object simply because different objects can have the same color, so just color alone won't cut out for which object it is if theres multiple obejcts that all have the same/similar colors. It also can't tell distance because it just show's which pixels are on screen, you can infer that the more pixels there are the closer an object is, but the object could also just be that big so it's unreliable. The line-following experiments are the final part where it includes robot movement on top of identifying a constantly changing image (the camera) it's basically the final connection where the robot takes a picture of the line it's currently on, then it adjusts it's turning to continue following this line without ever continuing off the line. A control choice for the images such as adding an obstacle for the learned detector cause the detector to not be able to identify the object at all, not even a general region showing that even a small obstacle could affect the final results super easily. Other limitations could be brightness, multiple objects with the same color, and slow reactions to sudden obstacles.
